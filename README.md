# Purchaseable-Marauders_EndlessSky
Plugin for the game Endless Sky that makes marauder and modified versions of ships available to the player at select locations of human pirate space. For ships that are directly descended from merchant models, like the Cutthroat, Scrapper, and Valkyrie, they are available on planets that sell the merchant model already, or on whatever pirate planets are near the shipyard that produced them.

This plugin also includes many of the modified ships in a variety of plugins. [See Below] The modified ships are available at Kraz Cybernetics, because I think it would make sense that such an organization would modify a bunch of existing ships.

If you would like to add your ships to the shipyard definitions, start a PR or message me on the ES Discord @BravoEchOneOne.

The idea of this plugin came directly from ZeroTWO002's Buyable Marauders. This plugin builds on the same concept of making Marauder ships buyable, but makes it more vanilla by restricting the purchase of the ships to pirate planets that already sold the normal variants.
Also changed is the edition of the Modified ships, which were not included in Zero's plugin.
